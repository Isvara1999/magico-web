# Proyecto: Mágico Ensueño - Sitio Web de Centro de Retiros

## Descripción del Proyecto
Desarrollé el sitio web completo para **Mágico Ensueño**, un centro de retiros y experiencias de bienestar ubicado en la montaña. El sitio web sirve como plataforma principal para promocionar sus servicios de estadías, retiros grupales, voluntariados y eventos, con un enfoque en la conexión con la naturaleza y el crecimiento personal.

## Tecnologías Utilizadas
- **Frontend**: React 18 con TypeScript para una experiencia de desarrollo robusta y tipada
- **Build Tool**: Vite para un desarrollo rápido y optimizado
- **Estilos**: Tailwind CSS para un diseño responsive y moderno
- **Routing**: React Router DOM para navegación entre páginas
- **Iconos**: Lucide React para iconografía consistente
- **Funcionalidades Adicionales**:
  - Marked.js para renderizado de Markdown
  - HTML2PDF.js para generación de PDFs
  - CropperJS para edición de imágenes
  - Microsoft Clarity para analíticas de usuario
- **PWA**: Configurado con Vite PWA plugin para funcionalidad offline
- **Despliegue**: Netlify para hosting y CI/CD

## Características Implementadas
- **Diseño Responsive**: Optimizado para móviles, tablets y desktop
- **Multilenguaje**: Soporte para español e inglés con contexto de idioma
- **Secciones Principales**:
  - Hero con video de fondo
  - Acerca de nosotros y filosofía
  - Pilares del centro
  - Experiencias y retiros
  - Voluntariados
  - Testimonios de clientes
  - Agenda de eventos
  - Información de ubicación y contacto
- **Sub-aplicaciones**:
  - Reset Vital 5D: Aplicación específica para retiros de bienestar
  - Familión: Sección dedicada a experiencias familiares
- **Integraciones**:
  - Botón de WhatsApp para contacto directo
  - Formularios de contacto
  - Google Analytics/Microsoft Clarity

## Desafíos Técnicos Resueltos
- Implementación de navegación suave con anclas
- Optimización de rendimiento con lazy loading
- Gestión de estado global para idioma
- Configuración de PWA con service workers
- Integración de múltiples bibliotecas de terceros

## Resultados
- Sitio web completamente funcional y responsive
- Experiencia de usuario fluida con navegación intuitiva
- Optimizado para SEO y rendimiento
- Desplegado en Netlify con actualizaciones automáticas
